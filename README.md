# Слова — тебе на А

Telegram Mini App · [играть](https://krownzzz36.github.io/slova/)

Классическая игра в слова: следующее слово на последнюю букву предыдущего.
`Арбуз → Зима → Анчоус`. Телефон — арбитр: держит очередь, помнит сказанное,
**проверяет, что слово настоящее** (существительное или прилагательное), считает
время. Одна рука, на ходу, работает офлайн.

Собрано по ТЗ v1.0. Главное, что добавлено к прототипу: настоящая проверка по
словарю (105k слов) — `РРРР` больше не проходит.

## Что внутри

```
index.html            разметка + стили, подключает модули
src/
  rules.js            чистые правила: checkMove, nextLetter, норм. (без DOM)
  morph.js            разбор формы слова + корневой ключ (без DOM)
  stats.js            расчёт статистики раунда (без DOM)
  dict.js             распаковка словаря, подсказки, детект тупика
  storage.js          CloudStorage → localStorage → память (с деградацией)
  ui.js               экраны, обработчики, ход партии, отрисовка
data/
  dict-data.js        сгенерированный словарь (full + частотный тир + др. ч.р.)
  full.txt/freq.txt/other.txt   дампы для проверки глазами
tools/
  build_dict.py       сборка словаря из pymorphy3 + wordfreq
  verify_dict.py      проверки качества словаря (ТЗ 4.1.5)
  requirements.txt
tests/
  rules.test.js       юнит-тесты правил (node --test, без зависимостей)
  e2e.spec.js         сквозные сценарии (Playwright)
  sandbox.html        тест запуска в <iframe sandbox> (ТЗ 12.1)
sw.js                 офлайн-кеш и мгновенное повторное открытие
```

Ключ архитектуры: `rules.js`, `morph.js`, `stats.js` **ничего не знают про DOM** —
словарь инъектируется через объект состояния. Поэтому правила покрыты тестами.

## Запуск локально

```bash

# открыть http://localhost:8777/index.html  (?debug=1 — подключит eruda-подобный лог)
```

Игра работает и в обычном браузере (без Telegram — деградирует в localStorage).

## Словарь

Собирается из морфологической базы, а не руками. Требуется Python 3.9+.

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r tools/requirements.txt
python3 tools/build_dict.py     # -> data/dict-data.js + дампы
python3 tools/verify_dict.py    # проверки качества, падает при нарушении
```

Итог: ~105k слов (≈62k сущ. + 43k прил.), частотный тир 14k, список других частей
речи 9k. Мат и 18+ отфильтрованы по корневому стоп-листу; невинные слова
(страх, гейзер, мандарин, херувим) сохранены. `dict-data.js` ~1.4 МБ, по сети с
gzip ~405 КБ, грузится **асинхронно после первого экрана**, кешируется Service
Worker'ом → второе открытие мгновенно и работает офлайн.

## Деплой в Telegram

1. Залить всю папку на статику по HTTPS (GitHub Pages / Netlify / Vercel /
   Cloudflare Pages). Бэкенд не нужен.
2. `@BotFather` → `/newbot` → сохранить токен.
3. `@BotFather` → `/newapp` → выбрать бота → картинка 640×360 → ссылка на
   приложение → получить `t.me/имя_бота/имя_аппа`.
4. `/setmenubutton` → та же ссылка (кнопка в меню бота).
5. Проверить на живом телефоне: тёмная тема, безопасные зоны, клавиатура,
   тактильный отклик, работа в самолётном режиме после первой загрузки.

**Кеш Телеграма агрессивный.** При обновлении поднимайте версию: константа `V` в
`src/ui.js` (идёт в `?v=` к словарю и SW) и `CACHE` в `sw.js`.

## Что реализовано из ТЗ

- **P0** Настоящая проверка по словарю (сущ./прил.), `РРРР`/`ЫОАН` не проходят.
- **P0** Правила приёма слова `checkMove` со всеми ветками и сообщениями (§7).
- **P0** «Всё равно засчитать» → слово запоминается в «Свои слова» и проходит впредь.
- **P0** Кнопка «Завершить раунд» (+ крестик), пустой раунд → на старт.
- **P1** Разбор формы слова (подсказка правильной формы), однокоренные (тумблер).
- **P1** Подсказки: маска → слово, +5 с, лимит.
- **P1** Итоги: победитель, разбор раунда, распределение по буквам в %, злая/быстрая
  буква, разбор по игрокам.
- **P2** Продолжение прерванного раунда, «Свои слова», пропуск «й», серия, «Поделиться».

Не тронуты по требованию ТЗ: правило последней буквы, шахматные часы, формула
победителя, отмена хода.

## Режимы и настройки (расширение v2)

Всё настраивается тумблерами/ползунками на экране старта:

- **Имена, города, страны** — отдельные тиры словаря (имена/фамилии 28,9k,
  гео 5,7k). Выкл по умолчанию; когда выкл — «Москва» отбивается понятной
  причиной с ручным зачётом.
- **Любые части речи** — принимать глаголы/наречия и т.п. (иначе только сущ./прил.).
- **Пропускать «й»** — по умолчанию вкл: после «трамвай» ход сразу на «а».
- **Жизни** (выкл / 3 / 5) — пас или таймаут снимает сердечко; кончились — игрок
  выбывает, последний оставшийся побеждает.
- **Игра на одного** — 1 игрок, сам с собой (эндлесс, завершаешь вручную).
- **Детский режим** — пресет: без таймера, подсказки без лимита, всё прощает.
- **Режим заданий** — «закончи на С» → +3 очка за выполнение, очки в статистике.
- **Сменить букву** (3 раза за игру) — ответить на предпоследнюю букву.
- **Пауза** — останавливает часы, оверлей с «Продолжить». Плюс авто-пауза при
  сворачивании/гашении экрана — фоновое время не «съедается».
- Кнопка **«Завершить игру»** — крупная и понятная, внизу игрового экрана.

Буква «Ы» (как и «Ь», «Ъ») никогда не выпадает для ответа — слов на них нет.

## UX-слой (ТЗ v3, `docs/ТЗ-UX-v3.md`)

Понятность первых секунд, тон и повод вернуться:

- **Онбординг** «живой цепочкой» при первом запуске (Арбуз→Зима→Автобус→?), ссылка
  «Как играть?» — открыть повторно.
- **Две двери со старта**: «Играть вдвоём» и «🧸 Для малыша»; продвинутые настройки
  свёрнуты в «⚙ Настройки игры».
- **Чей ход** — крупно: аватар-буква и имя в цвете игрока, вспышка при смене хода.
- **Тон сообщений** дружелюбный, с детской вариацией (в детском режиме мягче/короче);
  «Всё равно засчитать» — заметная равноправная кнопка.
- **Озвучка слова** (TTS `speechSynthesis`, отдельно от голосового ввода) — для тех, кто
  ещё не читает; включена в детском режиме.
- **Картинка-цепочка на шеринг** — итог раунда рисуется на canvas в PNG (как 🟩-сетка
  Wordle), уходит в семейный чат; текстовый фолбэк если платформа не умеет делиться файлом.
- **Дневной крючок**: «буква дня» (детерминированно, офлайн) и серия дней 🔥.
- Тач-таргеты ≥44px, `prefers-reduced-motion` уважается.

Словарь построен на морфологической базе OpenCorpora — это реальные, нормативные
русские слова (весь лексикон Ожегова входит в него как подмножество). Только
кириллица; заимствования, записанные по-русски (компьютер, интернет), проходят.
