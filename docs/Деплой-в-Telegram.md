# Деплой в Telegram — включить нативные фичи и Stars

Игра уже работает в вебе ([krownzzz36.github.io/slova](https://krownzzz36.github.io/slova/)) и офлайн.
Чтобы включить то, что работает **только внутри Telegram** — нативные вызовы-по-ссылке,
тактильный отклик (haptics), тему Telegram и **оплату Stars** для косметики — нужно
завести бота и мини-апп. Бэкенд не нужен, всё те же статические файлы.

Шаги, которые может сделать **только владелец аккаунта** (нужен твой Telegram):

---

## 1. Создать бота

1. Открыть [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Задать имя и username (например `slova_na_a_bot`). Сохранить **токен** — он понадобится
   позже (для Stars/уведомлений; для базовой игры не нужен, но пусть будет).

## 2. Создать мини-апп (Web App)

1. `@BotFather` → `/newapp` → выбрать бота.
2. Загрузить картинку **640×360**, короткое описание.
3. **Web App URL** → `https://krownzzz36.github.io/slova/` (адрес игры).
4. Задать короткое имя аппа (напр. `play`). BotFather выдаст ссылку вида
   **`t.me/slova_na_a_bot/play`** — это и есть точка входа.

## 3. Кнопка в меню бота

`@BotFather` → `/setmenubutton` → выбрать бота → указать ту же ссылку
`t.me/slova_na_a_bot/play` и подпись кнопки (напр. «Играть»).

## 4. Вписать ссылку в код (включит нативные вызовы-по-ссылке)

В `src/ui.js` найти константу:

```js
var BOT_APP_URL = '';   // после @BotFather /newapp вписать 'https://t.me/ИМЯ_БОТА/ИМЯ_АППА'
```

Вписать выданную ссылку:

```js
var BOT_APP_URL = 'https://t.me/slova_na_a_bot/play';
```

Поднять версию кеша (`V` в `src/ui.js` и `CACHE` в `sw.js`), закоммитить, запушить.
После этого «Бросить вызов» будет генерировать **нативную Telegram-ссылку**
(`t.me/.../play?startapp=...`) вместо веб-ссылки — друг открывает игру прямо в Telegram,
а не в браузере.

## 5. Проверить на живом телефоне

Открыть `t.me/slova_na_a_bot/play` с телефона и проверить:
- тёмная/светлая тема подхватывается из Telegram;
- тактильный отклик (haptics) на ходах;
- безопасные зоны (не перекрыто вырезом/навбаром);
- клавиатура не ломает верстку;
- работает офлайн после первой загрузки (самолётный режим);
- вызов-по-ссылке открывает нужный челлендж.

---

## Что это разблокирует

- **Нативные вызовы-по-ссылке** — вирусный рост в семейных/друзейских чатах (шаг 4).
- **Haptics и тема Telegram** — уже в коде, включатся автоматически внутри TG.
- **Stars-монетизация** (следующий шаг, ниже).

---

## Stars — монетизация косметики (Задача 11, после шагов выше)

Оплата **Telegram Stars** работает только внутри Telegram и требует немного бэкенд-логики
у бота (создать инвойс, поймать подтверждение). Это единственная часть, которую нельзя
сделать чисто на статике.

**Что продавать:** темы/скины оформления. Движок тем уже есть (`data/themes.js`,
скин «хохлома» как доказательство концепта) — можно добавить платные темы и скины букв.

**Как это работает (эскиз):**
1. В игре — экран «магазин тем»: бесплатные применяются сразу, платные — кнопка «Купить за ⭐N».
2. Кнопка вызывает у бота создание инвойса: Bot API `createInvoiceLink` с
   `currency: 'XTR'` (Stars) → мини-апп открывает оплату через
   `Telegram.WebApp.openInvoice(link)`.
3. Бот ловит `pre_checkout_query` (отвечает ok) и `successful_payment` → помечает у
   пользователя купленную тему (хранить можно в `CloudStorage` мини-аппа или у бота).
4. Игра при старте читает список купленных тем и разблокирует их.

**Минимальный бэкенд:** маленький бот-скрипт (webhook или long-polling) на любом
хостинге — только на два апдейта (`pre_checkout_query`, `successful_payment`) и один
метод (`createInvoiceLink`). Без базы можно на первых порах (хранить покупки в CloudStorage).

**Рекомендация:** это делать после того, как игра пожила в Telegram и видно спрос.
Для семейного продукта монетизация вторична — вирусный рост (шаг 4) важнее.
