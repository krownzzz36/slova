# Баланс и правила игры «Слова — тебе на А»

> Дизайн очковой экономики и условий победы. Этот же текст лежит в приложении
> (экран «📜 Правила и очки»), чтобы игроки понимали, за что даются очки.

---

## 1. Как считаются очки за слово

Каждое слово приносит **базу**, умноженную на **множители**:

```
очки = округл( база × скорость × серия )  + бонус задания
```

### База (за что слово «весит»)
- **Буквы** — сумма ценностей букв по шкале «Эрудита»
  (о,а,е,и,н,т,р,с,в,л = 1 … ж,з,х,ц,ч = 5 … ш,э,ю = 8 … ф,щ,ъ = 10).
  Длинные слова и слова с редкими буквами — дороже.
- **Редкость** — за редкое, «умное» слово доплата (до +12). Частое «слон» — почти
  без доплаты, редкое «сетчатка» — с полной. Награда за словарный запас, а не за длину.
- **Ловушка** — если слово заканчивается на трудную букву (ф, щ, ы, э…), доплата =
  ценность этой буквы. Ты и очки берёшь, и подставляешь соперника.

### Множитель за скорость (×0.9 … ×1.5)
Ответил быстро — множитель выше; долго думал — ниже. Работает даже без таймера.
В детском режиме скорость не влияет (всегда ×1.0) — ребёнка не гоним.

### Множитель за серию (×1.0 … ×2.0)
Личная серия: каждое слово подряд без осечки повышает множитель (+10% за слово,
до ×2.0). Серия **обнуляется**, если ты: спасовал, не успел, сменил букву или
воспользовался подсказкой. Награда за уверенную игру без костылей.

Итоговый множитель (скорость × серия) ограничен сверху ×3.0.

### Бонус задания
Если включён режим заданий и ты закончил слово на нужную букву — **+5 очков**
(сверху, не умножается).

## 2. Штрафы (за «костыли»)
- **Подсказка** — обнуляет серию (теряешь множитель) и добавляет «раздумье» ко
  времени хода (ниже множитель скорости). В детском — без штрафа.
- **Сменить букву** — стоит очков (−8) и обнуляет серию. В детском — бесплатно.
- **Пас / не успел** — обнуляет серию.

---

## 3. У игры всегда есть начало и конец

Партия должна как-то заканчиваться. Есть несколько условий (настраиваются на старте):

- **По разрыву очков** — как только один игрок отрывается на N очков
  (например 200 или 300), он побеждает. Игра не тянется бесконечно, но и не режется
  по таймеру — заканчивается, когда кто-то заслуженно ушёл в отрыв.
- **По жизням (сердечки)** — пас/таймаут снимает сердечко; кончились — выбыл;
  последний оставшийся побеждает.
- **Вручную** — «Завершить игру»; побеждает набравший больше очков.

Условия можно комбинировать (например, жизни + разрыв). Сверху во время партии
показывается **индикатор лидера** — кто ближе к победе.

---

## 4. Индикатор лидера

Полоска-перетягивание вверху: маркер стоит по центру при равенстве и уезжает к тому,
кто ведёт, тем дальше, чем больше разрыв. Если включена победа по разрыву — маркер,
дойдя до края, означает победу (это же и шкала прогресса к победе).

---

## 5. Правила слова (ядро, неизменно)
- Следующее слово — на последнюю букву предыдущего (ь/ъ/ы пропускаются; «й» — по
  настройке). Повторяться в партии нельзя.
- Принимаются существительные и прилагательные (имена/города/др. части речи — по
  настройке). Форма слова, однокоренные и опечатки — телефон подсказывает.
- Не нашлось слова / «не по теме» — можно «Всё равно засчитать».

## Константы баланса (для разработки, тюнятся в `src/score.js`)
| Что | Значение |
|---|---|
| Ценность букв | шкала «Эрудита» |
| Макс. бонус редкости | +12 |
| Скорость: быстро / медленно | ≤3 с → ×1.5, ≥20 с → ×0.9 |
| Серия: шаг / потолок | +10% за слово, до ×2.0 (10 слов) |
| Потолок общего множителя | ×3.0 |
| Бонус задания | +5 |
| Цена «сменить букву» | −8 |
| Разрыв для победы | выкл / 150 / 300 (настройка) |
